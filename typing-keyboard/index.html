Code & reuse

Every key, cap, knob, and display is HTML, CSS, or SVG. Copy the marked component styles, markup, and script into a project, then mount its root. Pass your own textarea as the second argument, or listen for the events below. The page also supports ?embedded for a gallery iframe.

const keyboard = EnochianKeyboard.mount(root, yourTextarea);
root.addEventListener('enochian:keyboard-input', ({ detail }) => {
  console.log(detail.value); // edited text and selection range
});
root.addEventListener('enochian:keyboard-parameter', ({ detail }) => {
  console.log(detail.parameter, detail.value); // volume / backlight, 0–100
});
// Call keyboard.destroy() when removing the component.

Space / Enter activates a focused key. Physical typing works within the keyboard or its textarea. Caps and Shift alter virtual typing; Shift releases after one key. Fn + F1/F2 changes backlight; Fn + F10 toggles sound; Fn + F11/F12 changes volume. Other function and modifier keys emit key events for your application. Sound is opt-in and synthesized locally.
